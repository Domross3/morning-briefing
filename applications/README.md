# Application packets

One markdown file per opportunity, written by the local hunt (`/hunt`) for
strong-fit roles. Each packet is meant to turn a ~40-minute application into a
~5-minute copy-paste:

- **Match analysis** — the role's stated requirements, one by one, against the
  profile: where you're strong, where you're thin, and what to address head-on
- **Resume bullets** — 3–5 tailored to this specific posting, drawn from real
  projects (Aspera, this briefing pipeline, the interview bot)
- **Cover letter draft** — in the user's voice, specific to the company
- **Screening answers** — drafts for the usual "why us / describe a project /
  biggest challenge" questions

Packets are committed so the morning email can link to them (`Packet →` on the
card). Nothing here is submitted automatically — applying is always a human
action.

Once you apply, log it with `/applied` so the role stops resurfacing and starts
appearing in follow-up nudges.
